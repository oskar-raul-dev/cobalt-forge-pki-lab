# cert/

Directorio de salida de **todos** los comandos de OpenSSL de los laboratorios (`docs/`): claves privadas, CSR, certificados, archivos de extensiones y control de serie.

Su contenido se genera localmente y **no se versiona** (ver `.gitignore`); en el repositorio solo existe este README.

> Aquí quedan claves privadas de CA (`*.key.pem`). No las compartas ni las subas a ningún lado.
